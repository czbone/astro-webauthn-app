# 動作確認

認証サーバーへ接続したあとの手動確認です。仕様は [participant-app.md](https://github.com/czbone/astro-user-webauthn2/blob/main/planning/participant-app.md) です。画面のホストは `APP_ORIGIN`、認証サーバーのホストは `AUTH_ORIGIN` です。

## 前提

認証サーバーの管理画面で、このアプリを登録します。

| 項目 | 値 |
| --- | --- |
| アプリ ID | Coolify または `.env` の `APP_ID` と同一。表示名は引き渡しに使わない |
| オリジン | `APP_ORIGIN`。パスは含めない |
| 戻り先 URL | `APP_ORIGIN/callback` |

ログインするユーザーに、そのアプリ ID への `AppGrant` を付けます。権限は `admin` または `user` です。seed 管理者の `User.role` が `admin` でも、`AppGrant` は自動では付きません。

アプリ未登録、戻り先 URL の不一致、付与が無い場合、認証サーバーは 403「引き渡し先のアプリを利用できません」を返します。参加アプリの `/callback` には戻りません。

## ログイン

未ログインで `APP_ORIGIN/` を開きます。参加アプリは `{AUTH_ORIGIN}/auth/handoff` へ送ります。認証サーバーにセッションがあり、パスキーと `AppGrant` があるときは、`/callback` を経由して `/` に戻ります。

`/` には次が出ます。

- 見出し「ログイン中」
- メールアドレス、名前、権限（`admin` は「管理者」、`user` は「利用者」）
- 権限が管理者のときだけ「付与一覧」のリンク
- 「ログアウト」

着地後、`APP_ORIGIN` の Cookie は `__Host-session` だけです。`__Host-handoff` は引き渡しの往復でだけ存在し、`/callback` の応答で削除されます。

## ログアウト

参加アプリの「ログアウト」は、このアプリのセッションだけを消します。`/logged-out` に「ログアウトしました」と「ホームへ戻る」が出ます。

`APP_ORIGIN` では `__Host-session` と `__Host-handoff` が消えます。認証サーバーのホストに残る `__Host-session` は消えません。参加アプリは認証サーバーのログアウトを呼びません。

`/logged-out` からは引き渡しを始めません。Cookie を見るときは、この画面に留まります。「ホームへ戻る」または `/` を開くと引き渡しが始まり、認証サーバーのセッションが残っていれば、ログイン画面なしで再び「ログイン中」になります。そのとき付く Cookie も `__Host-session` だけです。

## 権限

| 操作 | 結果 |
| --- | --- |
| 権限が `admin` で `/grants` を開く | このアプリの付与一覧。列はメールアドレス、名前、権限 |
| 権限を `user` にして `/grants` を開く | 403「この画面を利用する権限がありません」。`/` へのリンクだけ |
| ログイン中に、そのユーザーの `AppGrant` を外して `/` を開く | 「このアプリを利用する権限がありません」。ログアウトだけできる |
| 付与を戻して `/` を開く | 「ログイン中」に戻る |
| 認証サーバーで「すべてのアプリからログアウト」したあと `/` を開く | 自動では戻らず、認証サーバーのログイン画面に着く |

## Cookie

開発者ツールの Application → Cookies で、ホストごとに見ます。`__Host-session` と `__Host-handoff` は `HttpOnly` なので、ページ上の JavaScript からは見えません。`Domain` は無く、参加アプリと認証サーバーは別の Cookie です。

| 時点 | `APP_ORIGIN` |
| --- | --- |
| `/` にログインしたあと | `__Host-session` だけ |
| `/logged-out` に留まったあと | どちらも無い |
| `/` を開き直したあと | `__Host-session` だけ |

`__Host-handoff` の寿命は 5 分です。ログイン後の画面に残っているときは、引き渡しが完了していません。
